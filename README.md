# Abartılı Mazeret Fabrikası

## Dünyanın En Ciddi ve En Gereksiz Projesi

Bu repository, insanlık tarihinin en büyük sorunlarından birini çözmek için tasarlanmıştır: **Geç kalma mazeretleri**.

Artık "trafik vardı" demek zorunda değilsiniz. Bu fabrikadan çıkan mazeretler o kadar abartılı, o kadar absürt ve o kadar inandırıcı değildir ki, karşı taraf size acıyıp geçecektir.

### Nasıl Çalışır?

1. Python yüklü olsun (yoksa yükle, mazeret üretirsin).
2. `python mazeret_fabrikasi.py` yaz.
3. Bekle. Gerçekten bekle. Çünkü mazeret üretmek zaman alır.
4. Çıkan mazereti kopyala, yapıştır, kurtul.

### Örnek Çıktı

> Kusura bakma, geç kaldım çünkü asansör felsefe yaptı ve 'yukarı mı aşağı mı' diye sordu. Bir daha olmaz, söz.

### Neden Bu Proje?

Çünkü hayat zaten yeterince ciddi. Biz de ciddiyetle saçmalayalım.

Bu proje, modern teknolojinin en üst noktasıdır. Yapay zeka değil, yapay mazeret.

### Katkıda Bulunmak

Mazeret eklemek istersen PR at. Ama geç kalma, mazeretin olmasın.
